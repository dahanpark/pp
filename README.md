# 프라이어팰리스 리노베이션 공감 리포트

입주민 배포용 공감 리포트를 HTML 원본 중심으로 관리하는 저장소입니다.

공개용 HTML: https://dahanpark.github.io/pp/

## 구성

- `src/report.html`: 2026년 11월호 최신 웹 발행 원본 (19쪽)
- `releases/2026-11/261024_프라이어팰리스 리노베이션 공감리포트_26년 11월_Rev02.html`: 11월호 HTML 확정본 (스타일·설문 렌더러 포함)
- `releases/2026-10/report-Rev15.html`: 10월호 잠금본 HTML 보관
- `src/survey-results.html`: 10월 설문 결과 14문항·제출 222건을 별도로 관리하는 HTML (4쪽, A4 가로 인쇄 대응)
- `assets/`: 표지·로고 및 11월호 별첨 이미지 13점
- `scripts/build_pdf.cjs`: A4 가로 PDF 생성 스크립트
- `releases/2026-10/`: 10월호 보관본
- `releases/2026-11/`: 11월호 배포본

## 운영 원칙

1. 리포트 내용과 디자인은 모바일 HTML 원본인 `src/report.html`에서 먼저 수정합니다.
2. HTML 확정본을 `releases/YYYY-MM/`에 보관합니다. PDF는 필요한 시점에 브라우저에서 A4 가로로 출력합니다.
3. HTML과 PDF를 각각 화면·인쇄 매체에서 확인합니다.
4. 인증 제출 자료, 참가자 명단, 녹화 영상 등 민감한 첨부물은 사용자가 직접 관리하며 Git 저장소에 넣지 않습니다.
5. 변경 단위마다 Git 커밋을 남겨 발행 이력을 관리합니다.

대수선 주민 의견조사 결과는 `src/survey-results.html`과 11월호 8~11쪽에 동일한 집계 데이터로 표시합니다. 계획 조사 기간은 2026.10.7~10.25(19일간), 수록 응답은 10.24 12:33까지 접수된 222건입니다. 공지방 인원 138명·354명은 응답자 수와 다릅니다.

## PDF 생성·확인

브라우저 인쇄에서 용지를 A4, 방향을 가로, 배경 그래픽을 켜면 19쪽으로 출력됩니다. 11월호의 최신판은 Rev02 HTML이며, `releases/2026-11/`의 Rev01 PDF는 이전 판입니다. 주민 대화 원문·설문 개별 응답·인증 자료는 Git 저장소에 올리지 않습니다.
